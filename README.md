# PHP Words

Aplicación web estática para consultar y filtrar palabras reservadas de PHP de forma interactiva.

## Cómo ejecutar

1. Descarga o clona los archivos del proyecto en una carpeta local.
2. Abre el archivo `index.html` directamente en cualquier navegador web (haciendo doble clic o arrastrándolo a la ventana del navegador).
3. De forma opcional, si prefieres usar un servidor web local estático, puedes ejecutar cualquiera de los siguientes comandos desde la raíz del proyecto:
   - Con **PHP**:
     ```bash
     php -S localhost:8000
     ```
   - Con **Python**:
     ```bash
     python -m http.server 8000
     ```
   - Con **Node.js**:
     ```bash
     npx serve
     ```
   A continuación, accede a `http://localhost:8000` en tu navegador.
